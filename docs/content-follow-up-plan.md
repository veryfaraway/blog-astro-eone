## 1. 개발자 후원 시리즈 ("개발자 후원 시스템")

### 현재 상태

| 순서 | 포스트 | 경로 | 비고 |
|------|--------|------|------|
| 1편 | GitHub Sponsors 완전 가이드 | `dev/ko/2026/github-sponsors-setup.mdx` | |
| 2편 | Buy Me a Coffee vs Ko-fi | `dev/ko/2026/buymeacoffee-kofi-developer-sponsorship.mdx` | GSC 상위 유입 포스트 |
| 3편 | 토스·카카오페이 송금 링크 | `dev/ko/2026/toss-kakaopay-developer-sponsorship-korea.mdx` | **서비스 종료로 dead-end 처리됨** (본문 상단 경고 배너 + 대안으로 1·2편 링크) |

3편이 "이제는 쓸 수 없는 방법"으로 끝나 있어서, 시리즈가 자연스럽게 이어지는 4편이 없는 상태. "개발자 커피 후원" 같은 포괄적 쿼리는 검색 의도가 넓어서(플랫폼 비교, 실제 후원받는 법, 세금 처리 등) 후속편으로 커버할 여지가 크다.

### 후속편 아이디어

1. **실제로 후원 버튼을 블로그/README에 심는 법** — GitHub `FUNDING.yml`은 2편에서 다뤘지만, 블로그(Astro/Hugo 등) 자체에 후원 위젯을 붙이는 실전 가이드는 없음. Ko-fi 위젯 embed, 플로팅 버튼 UX, AdSense와 배치 충돌 안 나게 하는 법 등. → 이 블로그 자체(`blog-astro-eone`)에 후원 버튼을 실제로 붙이는 김에 "만들면서 기록"하는 형태로 쓰면 자연스러움.
2. **후원금 받으면 세금 신고는 어떻게 하나** — "개발자 커피 후원" 같은 넓은 쿼리가 다음에 궁금해할 지점. 기타소득/사업소득 여부, 해외 플랫폼(Ko-fi PayPal) 정산액 종합소득세 신고 실무. **주의: 세무 정보는 정확도가 중요하므로 실제 게시 전 세무사 상담 또는 국세청 공식 자료 교차 확인 필요.**
3. **네이버/카카오 기반 국내형 후원 대안 재조사** — 토스·카카오페이 송금 링크가 막힌 이후 새로 생긴 국내 대안이 있는지 (예: 카카오same같이가치, 네이버 해피빈, 오픈컬렉티브 등) 주기적으로 재조사해서 3편을 대체할 새 포스트 또는 3편 자체를 업데이트.
4. **Patreon 한국 정산 가이드** — Ko-fi/BMAC과 달리 정기 구독형 후원에 특화된 Patreon도 한국 정산 가능 여부·수수료 비교가 궁금할 수 있음. 시리즈에 자연스럽게 4편으로 편입 가능 (`series_order: 4`).

### 우선순위 제안

1번(실전 위젯 설치) → 4번(Patreon) → 2번(세금) → 3번(국내 대안 재조사) 순서 추천. 1번은 사이트에 실제로 적용하면서 쓸 수 있어 착수 난이도가 가장 낮음.

## 2. tmux 테마 후속 포스트

### 현재 상태

- `tools/ko/2026/tmux-theme-top5.mdx` — TOP 5 테마 + 폰트/색상 조합 소개. 단독 포스트 (시리즈 아님).
- 관련 tmux 포스트: `mac-iterm2-tmux-basic/tpm/cheatsheet/advanced` (4부작 "tmux 가이드" 시리즈), `tmux-conf-karabiner-json-full-setup.mdx`.
- "tmux 테마"(한글)와 "tmux theme"(영문) 모두 검색되는 것으로 보아 국내/해외 검색 수요가 섞여 있음.

### 후속편 아이디어

1. **테마별 단독 딥다이브** — TOP5 중 반응 좋은 테마(예: Catppuccin, Dracula, Gruvbox, Tokyo Night 등) 하나씩 골라 설치법 + `.tmux.conf` 스니펫 + 스크린샷 비교로 개별 포스트화. TOP5 포스트에서 "자세히 보기" 링크로 연결하면 내부링크 시너지.
2. **나만의 tmux 테마 직접 만들기** — 기존 테마 소개를 넘어서, `status-style`/`window-status-format` 등을 직접 커스터마이징하는 실전 가이드. "tmux 테마"로 유입된 사용자 중 기성 테마가 마음에 안 드는 사람을 타겟.
3. **tmux 테마 + Starship/Powerlevel10k 프롬프트 통일 가이드** — 터미널 전체(탭바+상태바+프롬프트) 색상을 하나의 팔레트로 맞추는 법. `macos-terminal-ghostty-tmux-karabiner.mdx`, `mac-dotfiles-guide.mdx`와 자연스럽게 엮임.
4. **tmux 플러그인 매니저(tpm)로 테마 설치 자동화** — 이미 `mac-iterm2-tmux-tpm.md`가 있으니 내용 중복 없이, TOP5에서 소개한 테마들을 tpm으로 설치하는 법만 별도로 짧게 정리(둘을 잇는 브리지 포스트).

### 우선순위 제안

1번(테마별 딥다이브)을 가장 먼저 — TOP5 포스트의 클릭률을 실제로 끌어올리는 내부링크 구조를 만들 수 있고, 개별 테마명으로 롱테일 키워드도 추가로 잡을 수 있음.

## 4. 용아맥(용산 아이맥스) 시리즈

### 현재 상태

- `culture/ko/2026/yongamac-seat-map.md` — 좌석 명당 총정리. GA4 기준 2026-06-24~07-21 활성 사용자 64명(타이틀 개편 전후 변형 3개 합산)으로 이번 기간 실사용자 유입 1위.
- 스파이더맨 브랜드 뉴 데이 개봉 시점에 맞춰 "아이맥스 vs 돌비시네마 vs 스크린X 비교" 포스트도 별도로 존재(활성 사용자 6명, 조회수 66 — 조회수 대비 유저 수가 낮아 반복 재방문/봇 트래픽 가능성 있음, 순수 인기로 보기엔 주의 필요).
- title/description은 2026-07-20에 이미 한 차례 SEO 개선함(위 CTR 이슈 참고).

### 후속편 아이디어

1. **상영관별 딥다이브** — CGV 용산아이맥스 외에 메가박스 코엑스 돌비시네마, CGV 왕십리 등 개별 상영관 리뷰/좌석 가이드로 확장. 롱테일 키워드 확보 + 기존 총정리 포스트로 내부링크 연결.
2. **개봉작 연동 시즌 업데이트 루틴화** — 텐트폴 대작 개봉 때마다(이미 스파이더맨·오디세이로 한 차례 함) 예매 전쟁 대비 섹션을 갱신하는 걸 정기 루틴으로 정착.
3. **예매 매크로/타이밍 실전 팁** — GSC에서 "용아맥 예매 오픈 시간" 쿼리가 확인된 적 있음(위 CTR 이슈 참고). 오픈 시간 대응 팁을 단독 섹션 또는 별도 포스트로 확장.

### 우선순위 제안

1번(상영관별 딥다이브)을 우선 — 총정리 포스트의 트래픽을 실제로 뒷받침하는 근거 콘텐츠가 되고 개별 상영관명으로 롱테일 유입도 늘릴 수 있음.

## 5. 코딩 에이전트 비교 시리즈

### 현재 상태

- "코딩 에이전트 삼국지: Claude Code vs Codex vs Antigravity 2.0" (활성 사용자 23명), "코딩 에이전트, 다시 삼국지: Kimi K3 vs Claude Fable 5 vs GPT-5.6"(1명), "코딩 에이전트 초한지: Claude Fable 5 vs GPT-5.6"(2명) — 시리즈 합산 활성 사용자 26명으로 이번 기간 4위.
- "계속 이어지는 사극 네이밍" 컨셉으로 신모델 출시마다 후속편을 내는 구조가 이미 자리잡음.

### 후속편 아이디어

1. **신모델 출시 추적 후속편** — 새 코딩 에이전트/모델이 나올 때마다 시리즈를 잇는 게 검색 트렌드에 가장 민감하게 반응하는 방식. 별도 리서치 없이도 발매 시점에 맞춰 빠르게 발행하는 게 핵심.
2. **태스크별 심층 비교편** — "삼국지" 시리즈는 종합 비교 위주였으니, 리팩토링·디버깅·신규 기능 구현 등 구체적 태스크 하나를 정해 여러 에이전트로 실제 작업시켜 비교하는 심층편.
3. **서브에이전트/MCP 활용 실전 가이드** — 비교 시리즈에서 다룬 도구들의 활용법을 한 단계 더 깊게 다루는 방향(에이전트 자체 비교가 아니라 "잘 쓰는 법").

### 우선순위 제안

1번(신모델 추적)이 최우선 — 이 시리즈의 트래픽 동력은 "최신 비교"라는 시의성이므로, 다음 대형 모델 출시 시점에 맞춰 빠르게 대응하는 게 가장 중요.
