**Stacher**는 오랫동안 사랑받아 온 크로스 플랫폼(Cross-Platform) 유튜브 다운로더입니다. 내부적으로는 `yt-dlp`를 엔진으로 쓰지만, 터미널 명령어를 하나도 몰라도 클릭 몇 번으로 영상·오디오를 저장할 수 있게 GUI로 감싸놓은 앱입니다. 이번 글에서는 설치부터 화질 선택, 자막·재생목록 다운로드까지 Stacher 사용법을 처음부터 끝까지 정리합니다.

- 기본 사용법: URL 붙여넣기 → 포맷·화질 선택 → 다운로드
- 다운로드 경로 설정
- 자막 다운로드
- 재생목록(플레이리스트) 일괄 다운로드
- yt-dlp와의 관계, 그리고 언제 yt-dlp를 직접 쓰는 게 나은지

## Stacher란?

Stacher는 Electron 기반으로 만들어진 오픈소스 GUI 다운로더입니다. 유튜브뿐 아니라 `yt-dlp`가 지원하는 수백 개 사이트의 영상을 URL 붙여넣기만으로 다운로드할 수 있습니다. 화질 선택, MP3 음원 추출, 재생목록 일괄 다운로드 등 웬만한 유료 앱 못지않은 기능을 무료로 제공합니다.

<Alert type="tip">
Stacher의 다운로드 엔진은 `yt-dlp`입니다. 유튜브가 정책을 바꿔도 `yt-dlp`가 업데이트되면 Stacher도 함께 정상 동작합니다. 다만 GUI 앱 특성상 `yt-dlp` 자체보다 업데이트 반영이 며칠 늦을 수 있습니다.
</Alert>

## 설치 방법

### macOS

공식 GitHub 릴리즈 페이지에서 `.dmg` 파일을 받아 설치합니다. Homebrew Cask로도 설치할 수 있습니다.

```bash
brew install --cask stacher
```

### Windows

GitHub 릴리즈 페이지에서 `.exe` 인스톨러를 받아 실행하면 됩니다. 별도 설정 없이 설치 마법사를 따라가면 끝입니다.

### Linux

`.AppImage`, `.deb`, `.rpm` 패키지를 배포판에 맞게 받아 설치합니다. AppImage는 실행 권한만 부여하면 별도 설치 없이 바로 실행됩니다.

```bash
chmod +x Stacher-*.AppImage
./Stacher-*.AppImage
```

<Alert type="info">
Stacher는 내부적으로 `yt-dlp`와 `ffmpeg` 바이너리를 함께 번들링하거나 최초 실행 시 자동으로 내려받습니다. 별도로 `yt-dlp`를 미리 설치해 둘 필요는 없습니다.
</Alert>

## 기본 사용법

### 1. URL 붙여넣기

유튜브에서 다운로드할 영상의 URL을 복사한 뒤, Stacher를 열고 상단 입력창에 붙여넣습니다. Stacher가 자동으로 영상 정보(제목, 길이, 사용 가능한 화질 목록)를 불러옵니다.

### 2. 포맷 · 화질 선택

영상 정보가 로드되면 드롭다운에서 원하는 화질(4K, 1080p, 720p 등)과 포맷(MP4, MP3 등)을 선택합니다. 음원만 필요하다면 포맷을 MP3로 지정하면 영상 트랙 없이 오디오만 추출해서 저장합니다.

### 3. 다운로드 경로 설정

설정(Settings) 메뉴에서 기본 다운로드 폴더를 지정할 수 있습니다. 매번 저장 위치를 묻지 않고 지정한 폴더에 바로 저장되도록 해두면 반복 작업이 훨씬 편해집니다.

<Alert type="warning" title="고화질 다운로드 시 확인할 점">
4K·1080p 같은 고화질은 영상 트랙과 오디오 트랙이 분리되어 다운로드된 뒤 자동으로 합쳐집니다. 이 병합 과정에는 `ffmpeg`가 필요하므로, 다운로드 후 파일이 깨지거나 소리가 안 나온다면 `ffmpeg` 번들링이 제대로 됐는지 앱 설정을 확인하세요.
</Alert>

## 자막 다운로드

Stacher는 유튜브에 등록된 자막(자동 생성 자막 포함)도 함께 받을 수 있습니다. 다운로드 옵션에서 자막 언어를 선택하면 영상 파일과 함께 `.srt` 자막 파일이 저장됩니다. 언어 학습용 영상이나 강의 영상을 보관할 때 특히 유용합니다.

---

## 재생목록(플레이리스트) 일괄 다운로드

재생목록 URL을 붙여넣으면 Stacher가 목록 안의 전체 영상을 인식해서 목록으로 보여줍니다. 여기서 원하는 영상만 체크하거나 전체 선택 후 한 번에 다운로드 큐에 올릴 수 있습니다. 큐에 쌓인 항목은 순차적으로 처리되며, 진행 중에도 다운로드 큐에 항목을 추가하거나 제거할 수 있습니다.

## yt-dlp와의 관계 — 언제 터미널을 직접 쓰는 게 나을까

Stacher는 `yt-dlp`를 GUI로 감싼 도구이기 때문에, 기능적으로는 `yt-dlp`가 지원하는 옵션의 일부만 화면에 노출됩니다. 아래 경우라면 GUI보다 `yt-dlp`를 터미널에서 직접 쓰는 편이 낫습니다.

- 세밀한 다운로드 옵션(특정 포맷 코드 지정, 쿠키 활용, 속도 제한 등)이 필요할 때
- 여러 URL을 스크립트로 자동화해서 반복 다운로드할 때
- Stacher 업데이트가 늦어져 유튜브 정책 변경에 즉시 대응이 안 될 때

반대로 터미널이 부담스럽고 클릭 몇 번으로 끝내고 싶다면 Stacher만으로 충분합니다.

## 마치며

Stacher는 터미널 없이도 화질 선택, MP3 추출, 자막·재생목록 다운로드까지 웬만한 기능을 다 갖춘 무료 GUI 다운로더입니다. 설치도 간단하고 인터페이스도 직관적이라, 유튜브 다운로드를 가끔씩만 쓰는 사람에게는 `yt-dlp`를 직접 다루는 것보다 훨씬 부담 없는 선택입니다.
