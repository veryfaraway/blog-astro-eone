## 클로드 코드가 뭔가요

한 줄로 요약하면, **터미널에서 실행하는 AI 코딩 에이전트**입니다. Anthropic의 Claude 모델을 기반으로 하며, 단순히 코드를 "생성"해주는 게 아니라:

- 프로젝트 구조를 스스로 탐색하고
- 관련 파일을 찾아 읽고
- 코드를 수정하고
- 테스트/빌드를 실행해 결과를 확인하고
- git 커밋까지 정리해주는

일련의 작업 흐름을 하나의 대화형 세션 안에서 처리합니다. IDE 플러그인이 아니라 CLI 도구라서, 에디터를 가리지 않고 지금 쓰던 터미널 환경 그대로 붙일 수 있다는 점이 특히 좋았습니다.

## 왜 계속 쓰게 되는가

| 기존 방식 | 클로드 코드 |
|-----------|-------------|
| 코드 조각을 복붙해서 챗봇에 붙여넣기 | 프로젝트 전체 맥락을 스스로 읽고 파악 |
| "이 함수 고쳐줘" → 답변 복붙 → 직접 적용 | 파일을 직접 수정하고 diff로 확인·승인 |
| 리팩터링 후 테스트는 수동 실행 | 테스트·빌드까지 이어서 실행 |
| 여러 파일에 걸친 변경은 직접 추적 | 여러 파일을 오가며 일관되게 수정 |

특히 이 블로그처럼 **콘텐츠 스키마, 컴포넌트 규칙, 다국어(ko/en) slug 규칙**같이 프로젝트마다 다른 세부 규칙이 많은 경우, `CLAUDE.md`에 규칙을 적어두면 매번 설명하지 않아도 그 맥락을 지키면서 작업해주는 점이 특히 유용했습니다.
