맥으로 일하다 보면 하루에도 수십 번 반복하는 동작이 있습니다. 브라우저 창 모서리를 잡고 화면 왼쪽 절반에 맞추고, 에디터를 오른쪽에 붙이고, 조금씩 어긋난 걸 다시 드래그하고. 윈도우의 스냅 기능에 익숙한 사람이라면 맥으로 넘어온 첫 주에 반드시 검색하게 되는 그 문제입니다.

**윈도우 관리 앱(window manager)** 은 이 반복을 단축키 하나로 줄여줍니다. 그런데 [클립보드 관리 앱](/tools/mac-clipboard-manager-apps)과 똑같은 질문이 여기서도 나옵니다. **이미 [Raycast](/tools/raycast-complete-guide-2026)를 쓰고 있다면, 창 관리 앱을 또 깔아야 할까요?** macOS 자체도 이제 타일링을 지원하는데요.

결론부터 말하면 **무료 플랜 기준으로도 Rectangle·Magnet을 대체하기에 충분합니다.** 다만 Raycast가 무료로 못 하는 지점이 명확하게 세 가지 있습니다. 그 경계선을 정확히 그어보겠습니다.

## 먼저: macOS 기본 타일링으로 어디까지 되나

앱을 깔기 전에 확인해야 할 게 있습니다. macOS Sequoia부터 창 타일링이 OS에 들어왔고, Tahoe에서도 그대로 제공됩니다. 의외로 이걸 모르고 앱부터 찾는 분이 많습니다.

**쓰는 방법은 세 가지입니다.**

- 창을 화면 가장자리로 **드래그**하면 배치 미리보기가 뜹니다
- 초록색 버튼에 **커서를 올리면** 왼쪽/오른쪽/위/아래/사분면 메뉴가 나옵니다
- **키보드 단축키**로 바로 실행합니다

기본 단축키는 이렇습니다.

| 동작 | 단축키 |
| :--- | :--- |
| 화면 채우기(Fill) | `fn` + `⌃` + `F` |
| 가운데 정렬 | `fn` + `⌃` + `C` |
| 왼쪽 / 오른쪽 절반 | `fn` + `⌃` + `←` / `→` |
| 위 / 아래 절반 | `fn` + `⌃` + `↑` / `↓` |
| 이전 크기로 되돌리기 | `fn` + `⌃` + `R` |
| 두 창 좌우 배치 | `fn` + `⌃` + `⇧` + `←` / `→` |
| 한 창 + 사분면 배치 | `fn` + `⌃` + `⌥` + `⇧` + `←` / `→` |

**한계도 분명합니다.** 3분할·6분할 같은 세로 삼등분이 없고, 모디파이어가 세 개씩 붙어 손이 꼬이며, 멀티 모니터 간 창 이동 명령이 없습니다. 무엇보다 **단축키를 내 손에 맞게 바꿀 수 없습니다.**

<Alert type="tip" title="여기서 갈립니다">
"창을 반으로 나누는 것"만 하루 한두 번 한다면 앱이 필요 없습니다. 이 글의 나머지는 **하루 수십 번 하는 사람**, 그리고 **3분할과 멀티 모니터가 필요한 사람**을 위한 내용입니다.
</Alert>

## Raycast 무료 Window Management, 정확히 어디까지 되나

가장 많이 오해하는 부분입니다. Raycast의 창 관리는 **Pro 기능이 아니라 무료 코어 기능**입니다. 공식 가격표에도 Clipboard History·Quicklinks·Snippets와 나란히 무료 플랜의 "Core features"로 적혀 있습니다.

무료와 Pro를 가르는 선은 **딱 하나, "직접 정의하느냐"** 입니다.

| 항목 | 무료 | Pro |
| :--- | :---: | :---: |
| 절반 / 삼분할 / 사분면 / 육분할 프리셋 | ✓ | ✓ |
| Maximize / Almost Maximize / Center / Reasonable Size | ✓ | ✓ |
| 원하는 명령에 핫키 지정 | ✓ | ✓ |
| 런처에서 이름으로 검색해 실행 | ✓ | ✓ |
| 멀티 모니터 간 창 이동 | ✓ | ✓ |
| 데스크탑(Spaces) 간 창 이동 | ✓ | ✓ |
| Deeplink로 외부에서 호출 | ✓ | ✓ |
| **Create Command** (내가 정한 크기·위치·오프셋) | ✗ | ✓ |
| **Create Layout** (여러 앱 배치를 통째로 저장) | ✗ | ✓ |

즉 **Rectangle 무료판이 하는 일은 Raycast 무료판이 전부 합니다.** 프리셋 가짓수는 오히려 Raycast 쪽이 더 많습니다. Pro 결제 압박이 걸리는 지점은 "프리셋에 없는 크기가 필요하다" 또는 "여러 앱 배치를 저장해두고 싶다", 이 둘뿐입니다.

<Alert type="warning" title="주의: 기본 핫키는 비어 있습니다">
Raycast를 설치했다고 창 관리 단축키가 저절로 생기지는 않습니다. **핫키를 직접 지정하기 전까지는 아무 일도 일어나지 않습니다.** "Raycast에 윈도우 관리가 있다던데 안 되던데요"의 99%가 이 이유입니다. 아래 1번부터 하세요.
</Alert>

## Raycast 창 관리 최대 활용 팁 8가지

무료 플랜 기준으로 전부 됩니다.

### 1. Rectangle 키맵을 그대로 이식하기

`Settings` → `Extensions` → `Window Management`에서 각 명령에 핫키를 지정합니다. 이미 Rectangle이나 Magnet을 쓰던 분이라면 **쓰던 키를 그대로 옮기세요.** 적응 기간이 0이 됩니다.

| 명령 | 추천 핫키 |
| :--- | :--- |
| Left Half | `⌃⌥←` |
| Right Half | `⌃⌥→` |
| Maximize | `⌃⌥↵` |
| Almost Maximize | `⌃⌥⇧↵` |
| Center | `⌃⌥C` |
| Top Left / Top Right | `⌃⌥U` / `⌃⌥I` |
| Bottom Left / Bottom Right | `⌃⌥J` / `⌃⌥K` |
| Next Display | `⌃⌥⌘→` |

이거 하나 안 하면 나머지 7개는 의미가 없습니다.

### 2. 삼분할·육분할로 넓은 모니터 쓰기

27인치 이상 외장 모니터에서 절반 분할은 너무 큽니다. **First Third / Center Third / Last Third**, 그리고 **First Two Thirds / Last Two Thirds** 조합이 실질적인 주력이 됩니다.

- 왼쪽 3분의 2에 에디터, 오른쪽 3분의 1에 터미널
- 가운데 3분의 1에 문서, 양쪽에 참고 자료

울트라와이드라면 육분할(Sixths)까지 내려가야 쓸 만해집니다. macOS 기본 타일링에는 아예 없는 영역입니다.

### 3. 핫키를 아끼고 런처로 부르기

자주 안 쓰는 명령까지 전부 핫키를 심으면 외우지 못합니다. **하루 열 번 이상 쓰는 것만 핫키, 나머지는 런처에서 이름으로** 부르세요.

명령마다 **Alias**를 지정하면 더 빨라집니다. `Left Two Thirds`에 `l2`를 붙여두면 Raycast를 열고 `l2` + 엔터로 끝납니다. 핫키 슬롯을 낭비하지 않고도 프리셋 전체를 손에 넣는 방법입니다.

### 4. 멀티 모니터 명령을 따로 심기

노트북 + 외장 모니터 조합이라면 이 세 개가 체감이 가장 큽니다.

- **Move to Next / Previous Display** — 창을 옆 모니터로 던지기
- **Restore** — 창을 원래 크기·위치로 되돌리기 (모니터를 뽑았다 꽂았을 때 유용)
- **Center on Display** — 화면 중앙에 적당한 크기로 정렬

특히 **Restore**를 한 번 써보면 왜 필요한지 바로 이해됩니다. 도킹을 자주 붙였다 떼는 환경에서 창이 흐트러지는 문제를 되돌려 줍니다.

### 5. 데스크탑(Spaces) 이동까지 한 번에

창 배치와 별개로, **Move Window to Next / Previous Desktop** 명령이 있습니다. 미션 컨트롤에서 창을 마우스로 끌어 옮기던 동작이 단축키 하나로 줄어듭니다. 작업 공간을 용도별로 나눠 쓰는 분이라면 창 분할보다 이쪽이 더 자주 손이 갑니다.

### 6. Hyper 키로 단축키 충돌 피하기

`⌃⌥` 조합은 IDE·터미널과 자주 충돌합니다. Karabiner-Elements로 `Caps Lock`을 **Hyper 키(`⌃⌥⇧⌘` 동시 입력)** 로 바꿔두면 어떤 앱과도 겹치지 않는 단축키 공간이 통째로 생깁니다.

`Hyper` + `←` = 왼쪽 절반, `Hyper` + `↵` = 최대화. 이런 식으로 창 관리 전체를 한 손에 몰아넣을 수 있습니다. 설정은 [Karabiner-Elements 가이드](/tools/karabiner-elements-guide-1)를 참고하세요.

### 7. Deeplink로 자동화에 끼워 넣기

각 창 관리 명령은 **Deeplink**를 뽑아낼 수 있습니다. 이 링크를 단축어(Shortcuts) 앱이나 셸 스크립트에서 호출하면, "회의용 배치"를 Raycast 밖에서도 트리거할 수 있습니다.

```bash
open "raycast://extensions/raycast/window-management/left-half"
```

무료 플랜에서 저장 레이아웃(Create Layout)을 못 쓰는 걸 우회하는 현실적인 방법이기도 합니다. 앱 실행 + 창 배치를 셸 스크립트로 순서대로 엮으면 됩니다.

### 8. 하나만 남기고 나머지는 지우기

Rectangle과 Raycast를 동시에 켜두고 서로 다른 키를 심어두면, **어느 앱이 어느 키를 잡고 있는지 몰라서 손이 느려집니다.** 두 앱이 같은 핫키를 등록하면 조용히 한쪽이 무시되기도 합니다.

창 관리는 근육 기억으로 쓰는 도구입니다. Raycast로 옮기기로 했다면 Rectangle은 **로그인 항목에서 빼고 완전히 종료**하세요.

## Raycast만으로 부족해지는 순간 3가지

### 1. 프리셋에 없는 크기가 필요하다 → Rectangle Pro

"화면의 62%, 왼쪽에서 20px 떨어뜨려서" 같은 요구는 무료 플랜에서 막힙니다. **Create Command**가 Pro 기능이기 때문입니다.

Raycast Pro는 월 $8(연간 결제)부터인데, 창 관리 하나 때문에 구독하기는 아깝습니다. 그렇다면 **[Rectangle Pro](https://rectangleapp.com/pro)** 가 $9.99 일회성으로 같은 문제를 풉니다.

```bash
brew install --cask rectangle
```

> Homebrew가 없다면 [맥 Homebrew 설치 가이드](/tools/install-homebrew-2026)를 먼저 참고하세요. 위 명령은 무료판 Rectangle이고, Pro는 공식 사이트에서 10일 체험 후 구매합니다.

Rectangle Pro가 추가로 주는 것은 커스텀 크기 말고도 꽤 됩니다.

- 화면 아무 곳에나 **스냅 타깃** 배치
- 창을 원하는 방향으로 **던지기(throw)** — 16가지 크기·위치
- 여러 앱을 한 단축키로 배치하는 **워크스페이스**
- 창을 화면 가장자리에 **숨겨두기(stash)** — 커서를 대면 슬라이드
- iCloud로 설정 동기화, 라이선스 하나로 맥 3대

### 2. 여러 앱 배치를 저장해두고 싶다 → Moom

"코딩 모드"는 에디터·터미널·브라우저·슬랙 네 개가 정해진 자리에 있어야 하고, "글쓰기 모드"는 또 다릅니다. 이걸 매번 단축키 네 번으로 만드는 건 결국 안 하게 됩니다.

**[Moom](https://manytricks.com/moom/)** 의 진짜 강점이 여기입니다. 창 배치를 통째로 **저장해두고 트리거 하나로 복원**합니다. 외장 모니터를 연결하는 순간 저장된 레이아웃이 자동으로 적용되게 할 수도 있습니다.

가격은 **$15 일회성**(기존 사용자 업그레이드 $8), Many Tricks 공식 사이트에서 직접 구매합니다. 무료 체험이 있으니 "내가 정말 레이아웃을 저장해서 쓰는 사람인가"를 먼저 확인해 보세요. 의외로 안 쓰는 사람이 많은 기능입니다.

Raycast Pro를 이미 쓰고 있다면 **Create Layout**으로 같은 일이 가능합니다. 추가 지출이 필요 없습니다.

### 3. 키보드가 아니라 손끝으로 하고 싶다 → Magnet·Swish·Loop

단축키를 외우는 게 체질이 아닌 분들이 있습니다. 이 경우 Raycast는 애초에 맞지 않는 도구입니다.

- **[Magnet](https://magnet.crowdcafe.com/)** — $4.99 일회성, macOS 13 이상. 창을 화면 가장자리로 끌면 스냅되는 방식이 주력입니다. App Store에서 가장 많이 팔린 창 관리 앱이고, 설정할 게 거의 없다는 게 장점입니다.
- **[Swish](https://highlyopinionated.co/swish/)** — $16 일회성(14일 체험, 맥 2대). **타이틀바 위에서 트랙패드를 스와이프**하면 창이 배치됩니다. 창을 잡아 끌 필요가 없어서 손목 이동이 가장 적습니다. 핀치로 닫기·전체화면 같은 30여 가지 제스처가 있고, Setapp 구독에도 포함됩니다.
- **[Loop](https://github.com/MrKai77/Loop)** — 무료·오픈소스. 지정한 키를 **누르고 있는 동안 방사형 메뉴**가 뜨고, 커서를 방향으로 밀어 배치를 고릅니다. 키를 외우는 대신 방향만 기억하면 됩니다.

```bash
brew install --cask loop
```

<Alert type="tip" title="한 걸음 더: 자동 타일링">
창을 "배치"하는 게 아니라 **애초에 겹치지 않게 자동 정렬**되길 원한다면 타일링 윈도우 매니저가 답입니다. **[AeroSpace](https://github.com/nikitabobko/AeroSpace)** 는 i3 스타일 타일링을 텍스트 설정 파일로 다루고, macOS 기본 Spaces에 의존하지 않는 자체 가상 워크스페이스를 씁니다. **SIP를 끄지 않아도 됩니다.** 다만 1.0 이전 공개 베타라 설정 형식이 바뀔 수 있습니다.

더 오래된 선택지인 **yabai**는 강력하지만 일부 기능에 SIP 부분 해제가 필요합니다. 보안 설정을 건드리는 게 부담이라면 AeroSpace부터 보세요.
</Alert>

## 그래서, 당신은 어느 쪽인가

| 사용자 유형 | 추천 조합 |
| :--- | :--- |
| 창 분할을 가끔 함 | **macOS 기본 타일링 단독** |
| Raycast 사용 중, 프리셋으로 충분 | **Raycast 단독** (핫키만 설정) |
| Raycast 안 씀, 무료로 단축키 스냅만 | **Rectangle 단독** |
| 커스텀 크기·워크스페이스가 필요 | **Rectangle Pro** ($9.99) |
| 작업 모드별 레이아웃을 저장해서 씀 | **Moom** ($15) 또는 **Raycast Pro** |
| 마우스·드래그 중심 | **Magnet** ($4.99) |
| 트랙패드 제스처 중심 | **Swish** ($16) |
| 터미널·설정 파일이 편한 개발자 | **AeroSpace** (무료) |

가장 흔한 실수는 **창 관리 앱을 두 개 이상 켜두는 것**입니다. 단축키가 서로 잡아먹혀서 "가끔 안 되는" 상태가 되고, 원인을 찾는 데 한 시간을 씁니다. 하나를 정하고 나머지는 지우세요.

## 자주 묻는 질문

**Q. macOS에 창 스냅 기능이 원래 있나요?**
있습니다. Sequoia부터 OS 차원의 타일링이 들어왔고, 드래그·초록 버튼 메뉴·`fn` + `⌃` + 방향키로 쓸 수 있습니다. 다만 삼분할이 없고 단축키를 바꿀 수 없어서, 자주 쓰는 사람에게는 부족합니다.

**Q. Raycast 창 관리는 유료인가요?**
아닙니다. 프리셋 배치·핫키 지정·멀티 모니터 이동까지 전부 무료 플랜에 포함됩니다. Pro가 필요한 건 **직접 정의한 크기(Create Command)** 와 **저장 레이아웃(Create Layout)**, 이 둘뿐입니다.

**Q. Rectangle과 Raycast를 같이 써도 되나요?**
동작은 하지만 권하지 않습니다. 같은 핫키를 두 앱이 등록하면 한쪽이 조용히 무시되고, 어느 앱이 처리하는지 헷갈리게 됩니다. 옮기기로 했다면 이전 앱은 종료하고 로그인 항목에서 빼세요.

**Q. 창 관리 앱이 배터리를 많이 먹나요?**
Rectangle·Raycast 수준의 앱은 평소에 아무 일도 하지 않다가 단축키가 눌릴 때만 동작하므로 체감 부하가 없습니다. 다만 **자동 타일링 매니저(AeroSpace·yabai)** 는 창 이벤트를 계속 감시하므로 성격이 다릅니다.

**Q. 손쉬운 사용 권한을 꼭 줘야 하나요?**
네. 다른 앱의 창 크기와 위치를 바꾸려면 접근성 권한이 필요합니다. macOS 기본 타일링만 예외입니다. 권한을 줬는데도 동작하지 않으면, 앱을 업데이트한 뒤 목록에서 **체크를 껐다 켜는 것**이 가장 흔한 해결책입니다.

## 마무리

정리하면 이렇습니다.

1. **창을 가끔 나눈다면 macOS 기본 타일링으로 끝납니다.** 앱을 찾기 전에 `fn` + `⌃` + 방향키부터 눌러보세요.
2. **Raycast를 쓰고 있다면 창 관리 앱을 깔 이유가 없습니다.** 핫키만 심으면 Rectangle 무료판과 같은 일을 합니다.
3. **커스텀 크기와 저장 레이아웃**만이 돈을 낼 만한 이유입니다. 각각 Rectangle Pro($9.99)와 Moom($15)이 답입니다.

Raycast를 이제 막 시작했다면 [Raycast 완벽 가이드](/tools/raycast-complete-guide-2026)와 [Raycast 실전 가이드](/tools/raycast-advanced-guide-2026)를, Pro 결제를 고민 중이라면 [Raycast Pro 7일 무료체험 활용법](/tools/raycast-pro-trial-guide)을 함께 읽어보시길 권합니다. 같은 방식으로 클립보드 앱을 정리한 [맥 클립보드 관리 앱 추천](/tools/mac-clipboard-manager-apps)도 이어서 보시면 앱 개수를 확실히 줄일 수 있습니다.
