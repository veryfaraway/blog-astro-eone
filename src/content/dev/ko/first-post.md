# 주경야근 블로그에 오신 것을 환영합니다! 🎉

안녕하세요! **주경야근** 블로그의 첫 포스트입니다. 이 블로그는 프로그래밍, 데이터분석, IT 트렌드에 대한 기술 블로그입니다.

## 블로그 소개

이 블로그는 다음과 같은 기술 스택으로 구축되었습니다:

- **Eleventy** - 정적 사이트 생성기
- **Tailwind CSS** - 유틸리티 기반 CSS 프레임워크
- **Nunjucks** - 템플릿 엔진
- **Prism.js** - 코드 하이라이팅

## 주요 기능

### 1. 카드형 레이아웃

블로그 홈에서 포스트들을 카드 형태로 깔끔하게 볼 수 있습니다.

### 2. 카테고리 & 태그

다양한 카테고리와 태그로 원하는 글을 쉽게 찾을 수 있습니다:

- Frontend
- Backend
- Modeling
- NoSQL
- DevOps
- AI/ML

### 3. 코드 하이라이팅

코드 스니펫을 아름답게 표시할 수 있습니다:

```javascript
// JavaScript 예제
const greeting = (name) => {
  console.log(`안녕하세요, ${name}님!`);
};

greeting("개발자");
```

```python
# Python 예제
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
```

### 4. 반응형 디자인

모바일, 태블릿, 데스크톱 모든 기기에서 최적화된 경험을 제공합니다.

## 앞으로의 계획

앞으로 다음과 같은 주제들을 다룰 예정입니다:

1. **프로그래밍 튜토리얼** - 실용적인 코딩 가이드
2. **데이터 분석** - Python, R을 활용한 데이터 분석
3. **IT 트렌드** - 최신 기술 동향과 분석
4. **개발 팁** - 생산성을 높이는 도구와 방법
